- The build itself succeeded ([line 256](#L256), [line 258](#L258)), but Netlify failed at deploy because it couldn't find the publish directory: "Deploy directory 'artifacts/3v-app/artifacts/3v-app/dist/public' does not exist" ([line 269](#L269)).

Netlify is effectively prefixing the publish path with the base, producing a duplicated path ([line 8](#L8)).
- Error type: configuration error (wrong publish directory). Cause: publish path in netlify configuration is relative to the repo root but base is also set to artifacts/3v-app, so Netlify concatenates them and ends up looking in a non-existent duplicated path.

Solution
1. Inspect your netlify configuration (likely netlify.toml at the repo root). Verify the file exists: https://github.com/ahbdb/voie-verite-vie-ea016620/blob/main/netlify.toml

2. Fix the publish path so it is correct relative to the configured base. You have two options:

- Preferred: keep base = "artifacts/3v-app" and set publish to the build output relative to that base (e.g. "dist/public"). Example netlify.toml change:
```toml
[build]
  base = "artifacts/3v-app"
  command = "corepack enable && pnpm install --frozen-lockfile && pnpm --filter @workspace/3v-app run build"
  publish = "dist/public"
```

- Alternative: remove/clear the base and set publish to the full path relative to the repo root (if you prefer a single absolute/relative path). For example:
```toml
[build]
  # remove or empty base
  # base = ""
  command = "corepack enable && pnpm install --frozen-lockfile && pnpm --filter @workspace/3v-app run build"
  publish = "artifacts/3v-app/dist/public"
```

3. Commit the change to netlify.toml (or update the Publish directory in your Site settings on Netlify to match the corrected path). If you update via the Netlify UI, be careful to keep Base directory and Publish directory consistent (don’t duplicate the same segment in both).

4. Verify locally before pushing:
- Run the same build command used by Netlify and check that the output folder exists:
```bash
# from repo root
corepack enable && pnpm install --frozen-lockfile
pnpm --filter @workspace/3v-app run build

# then check the path that will be published
ls -la artifacts/3v-app/dist/public
```
(If your netlify.toml uses base = "artifacts/3v-app", run ls -la artifacts/3v-app/dist/public; if publish is "dist/public" relative to base, the path Netlify will use is base + publish -> artifacts/3v-app/dist/public.)

5. Re-deploy on Netlify. The deploy should succeed once the publish path points to the actual build output directory.
