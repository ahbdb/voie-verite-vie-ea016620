NETLIFY CONFIGURATION FIX
========================

**PROBLÈME IDENTIFIÉ:** 
La Netlify UI a des paramètres qui override le netlify.toml correct.

**ÉTAPES À FAIRE MANUELLEMENT SUR NETLIFY:**

1. Va sur https://app.netlify.com → Sélectionne ton site
2. Clique sur "Site settings" → "Build & deploy" → "Build settings"
3. Modifie le "Build command":
   ❌ AVANT: npm install --legacy-peer-deps && npm run build
   ✅ APRÈS: corepack enable && pnpm install --frozen-lockfile && pnpm --filter @workspace/3v-app run build

4. Modifie le "Publish directory":
   ❌ AVANT: /opt/build/repo/dist
   ✅ APRÈS: artifacts/3v-app/dist/public

5. Clique "Save"
6. Clique sur "Deploys" → "Trigger deploy" → "Deploy site"

OU utilise l'interface Netlify CLI:
```bash
netlify deploy --build --prod
```

✓ Poussé le .nvmrc pour forcer Node 20

✓ netlify.toml est déjà correct

Après la correction, Netlify utilisera la bonne commande et publiera dans le bon dossier.
